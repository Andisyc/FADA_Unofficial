# FADA-TTT：部署期在线动力学适应设计提案

- 日期：2026-09-10
- 状态：**设计提案，待审查**。概念设计已闭环，未经任何实验验证。
- 来源：研究讨论会话整理，供审查 Agent 独立评估。审查者无需会话上下文。
- 前置阅读：FADA 论文（arXiv:2606.28476，本地 `~/OneDrive/Files-Embody/S2R_WBC_Locom/2026 0626 FADA ...pdf`）；本仓库 `note/fada/README.md`。

## 1. 问题

FADA 的适配流程是离线循环：zero-shot 部署 → 收集约 2 分钟（≈6000 步）目标域 rollout → 冻结 Planner、LoRA 微调 IDM → 重新部署。当部署动力学**在任务中途发生变化**（典型场景：拉箱子走直线时箱内被加重），已适配的策略立即失配（无法保持直线），唯一的修复手段是重新走一遍离线循环。

目标：让适配在部署期间**持续在线进行**，动力学阶跃后数十秒内恢复任务表现，无需停机、无需重新收集数据、无需 reward。

## 2. 核心洞察（整个设计的支点）

FADA 的适配损失（论文 Eq. 4.5）是**纯自监督逆动力学损失**：

$$\ell(\Delta\psi) = \big\| \Pi_1\, I_{\psi+\Delta\psi}(O^H_t, A^H_t, Y^{K,exec}_t) - a^{exec}_t \big\|^2$$

其全部输入——历史观测 $O^H$、历史动作 $A^H$、真实未来 $Y^{K,exec}$、已执行动作 $a^{exec}$——在部署时**每步自动可得**，无需标签、reward、示教或仿真快照。因此离线适配循环可以原样滚动为在线循环。这是 FADA 相对其他基座做 TTT 的结构性优势。

## 3. 设计总览

一句话：**FADA 的模块、损失、数据格式全部不动；把"离线收集→微调→重部署"替换为"影子 LoRA 在线训练、留出窗口验证、原子提交"的持续循环；默认冻结，仅在失配且数据充分时更新。**

```text
机器人端 (实时)                      服务器端 (异步, 可网线连接)
──────────────                      ──────────────────────────
控制通道 50Hz:                       日志流 (o,a) → 滑动窗口 buffer
  I_{ψ+Δψ_live}(O_H,A_H,Ŷ_planner)    (瞬态加权, 见 §4.5)
        ↓                            影子 Δψ_cand 训练 (Eq.4.5 + 锚定正则)
      a_t                            留出窗口验证 (见 §4.4)
每帧: 有无新版本 Δψ? ────网线──── 验证通过才发回: 新Δψ + 版本号
  有则帧边界原子换入                  断线/失败 → 机器人继续用现任, 安全降级
```

## 4. 关键机制

### 4.1 挂载点：LoRA on IDM，Planner 冻结

- 直接继承 FADA 的 Planner–IDM 角色分离（论文 §5.6 对照实验：动力学失配只改变 plan-to-action map，不改变意图）。
- Δψ(t) 的语义从"一次性校准快照"变为"时变动力学的在线估计量"——分析工具相应地从 few-shot 学习换成自适应控制（时间尺度分离、PE 条件）。
- 否决独立外挂网络：其影响动作只有两条路——最终动作残差（FADA §2.3 已批评为 black-box）或修正 IDM 输入（引入未验证的信用路径）；且独立网络在部署现场无初始化，样本量不支持。

### 4.2 监督与损失

- 损失原样使用 Eq. (4.5)，数据格式原样使用 $\mathcal{W}=(O^H, A^H, Y^{K,exec}, U^{K,exec})$ 原始窗口，**不加额外 encoder**（IDM 内部已有历史编码；额外压缩会把需要不同修正的动力学情形压进同一 latent）。
- 唯一加法：锚定正则 $\lambda\|\Delta\psi - \Delta\psi_{\text{incumbent}}\|^2$。锚的是**上一次提交的校准**（非零向量）：旧动力学本该遗忘（箱重已变），要防的只是同一工况内的梯度漂移。

### 4.3 双通道因果结构（"Tracker 固定运行 vs 微调需要真实状态"的解）

- 控制通道在时刻 $t$ 只能吃 planner 预测未来 $\hat Y_t^K$——真实未来此刻尚不存在，这是因果约束，离线 FADA 相同。
- 训练通道吃**重放**：起点为 $t-K$ 的窗口在时刻 $t$ 已全部实现，其 $Y^{K,exec}$ 成为可用的监督。监督因此天然滞后 K 步（K=6、50Hz → 120ms，可忽略）。
- 两次前向共享参数、互相只读；唯一的"写"发生在影子副本上，交接为原子换入。控制环与训练环分离线程/进程，控制优先；训练低频突发（每 k 步一次，参考 TT-VLA 消融 k=8 最优），单 GPU 即可承载，也可分离硬件经网线传 Δψ（LoRA 参数量约数百 KB，秒级以下事件，带宽无压力）。

### 4.4 影子提交协议（incumbent / candidate）

借自 VANE (arXiv:2608.09448) 的 propose–validate–commit 协议，且因 FADA 的监督式损失而更便宜：

1. candidate 在 buffer 上离线训练，**不接触控制**；
2. 验证：在**未参与训练的留出窗口**上比较 candidate 与 incumbent 的 IDM 损失——监督式损失使 candidate 可在 incumbent 采集的数据上离线评分，**无需实际执行**（VANE 必须真跑 matched pairs，本设计免掉）；
3. 原子提交或丢弃回滚。commit 判据定为工程经验项（损失在留出窗口上足够小/平台期），唯一硬性要求：判据不得使用训练 buffer 本身的损失（否则可被过拟合伪造）。

### 4.5 门控：失配 × 激励 2×2

在线闭环下，"IDM 损失下降"不再自动等于"任务改善"（数据分布由正在更新的模块自身产生，非平稳、自指）。门控信号：

| 信号 | 来源 | 语义 |
|---|---|---|
| 失配信号 | consistency gap（论文 §5.6 已定义）：同段历史下 IDM 吃预测未来 vs 真实未来的动作差；在线时真实未来滞后 K 步可得，**每步免费计算** | 是否该修 |
| 激励信号 | buffer 内窗口分布的丰富度（协方差特征量 / 新窗口与已有窗口相似度） | 是否能修 |

| | 激励充足 | 激励不足 |
|---|---|---|
| **失配大** | 全速更新（黄金窗口） | 冻结等待，或开启任务容差内探测（旋钮，默认关） |
| **失配小** | 冻结（无东西可修，更新即漂移） | 冻结 |

配套机制：

- **瞬态加权 buffer**：起步/加速/转弯/急停等瞬态窗口优先保留与训练（瞬态单位时间的动力学信息量远超稳态）；稳态窗口仅留少量代表。
- **梯度投影**：将梯度投影到 buffer 信息矩阵的显著特征子空间，未激励方向梯度归零——从结构上杀死 drift/bursting（经典自适应控制在无 PE 下的已知失效模式）。
- **任务容差内探测（可选旋钮，默认关）**：失配大但激励长期不足时，让指令在任务误差带内缓慢变化（如速度 ±5%）以主动制造激励。此旋钮即论文"适应速度 vs 任务精度"trade-off 曲线的横轴。
- 窄激励数据足够修复窄任务本身（箱重变化在直线数据中即可观测）；PE 约束的真正风险是腐蚀未练过的行为——这正是梯度投影要守的边界。

### 4.6 安全与降级

- 更新瞬态风险靠协议本身控制：live 策略只向"验证过更优"的状态移动，且 LoRA 小步慢变。
- 服务器/网络失效 → 机器人继续用 incumbent，最坏退化为今天的离线 FADA。

## 5. 已确认的决策（2026-09-10 会话内定案）

1. **不加防摔/恢复机制**：继承 FADA 假设"部署时 zero-shot 非灾难性"，载荷范围与 FADA 相当。写入 Limitation 而非机制。
2. **commit 判据走工程经验**：参考 FADA/LoRA 惯例（留出窗口损失收敛）；不设新理论判据。
3. **不记忆历史工况**：Δψ 为单一"当下估计量"，无版本库；遗忘旧工况是设计意图。论文声明收窄为"适应当前工况"，不做 lifelong memory 故事。

## 6. 非范围（explicit non-scope）

- 摔倒检测与恢复；灾难性 zero-shot 情形。
- 跨任务通用执行校准器（FADA Limitation 2，另一篇论文）。
- 外感知（地形几何、载荷分布显式表征；FADA Limitation 3）。
- 多工况记忆、lifelong 版本管理。
- 新网络组件：本工作不发明任何新模块，贡献在于证明既有组件可在闭环中持续运行。

## 7. 理论定位与文献依据

**定位**：failure class = 在线系统辨识 + 自适应控制；两个成熟结构各管一段——

- **自适应控制**（MRAC/L1、PE 条件、bursting 文献）管：Δψ 作为在线估计量的语义、激励约束、时间尺度分离、drift 失效模式。
- **TTA/TTT 文献**管：持续更新的工程可靠性——CoTTA (CVPR'22, stochastic restore)、EATA (ICML'22, 可靠性过滤 + Fisher 抗遗忘)、SAR (ICLR'23, 大梯度剔除 + 锐度感知防坍缩)、NOTE (NeurIPS'22)、RMT (CVPR'23)、VANE (2026, 影子提交协议 + 反向传播减少 98.7%)、TT-VLA (ACL'26, 更新频率消融)、RoboTTT (2026, fast weights 架构)。

**空白证据**：人形 locomotion 领域的部署期适应全部为 in-context / 无权重更新——SplitAdapter (2026)、Any2Track/AnyAdapter (2025)、ADAPT (2026)（本地 PDF 已核）。"在线更新执行模块权重"在连续接触全身控制中无人占据，即本工作的贡献槽位。

**状态判定**：THEORY-ALIGNED，含一个 EVIDENCE-GAP（见 §8 判据 a）。

## 8. 证伪预测与判别实验

**地基假设（唯一未被证据覆盖的环节）**：在线闭环、非平稳数据下，IDM 损失下降仍代理任务表现改善。FADA 的全部证据都是离线的；在线版本无证据。

判别实验（同时是论文 Figure 1）：

```text
平台:   现有 FADA sim-to-sim 栈 (IsaacSim source → MuJoCo target)
场景:   Loco.+Payload 直线牵引, 中途 payload 阶跃 (如 3kg → 6kg)
对照:   FADA-zs (不适应) / 离线 FADA 重新微调 (性能上限) / 本方法 (在线 TTT)
观测:   (a) 在线 IDM 损失轨迹 (b) 直线跟踪误差轨迹 (c) 恢复时间
判据:   地基假设成立 ⟺ (a)(b) 同向;
        工作成立 ⟺ 恢复时间 ≪ 离线重收集周期, 终态误差接近离线上限
附带:   未训练行为 (转弯/急停) 上的漂移量 —— 梯度投影有效性的直接证据
```

该实验不通过 → 回到监督信号层面重新设计，而非调参。

## 9. 后续消融矩阵（判别实验通过后）

逐项拆除：锚定正则 / 失配门控 / 激励门控 / 梯度投影 / 影子提交（vs 直接在线更新）/ buffer 瞬态加权（vs 均匀）。基线组另含 RMA 类 in-context 与 VANE 协议直接迁移版。

| 风险 | 等级 | 缓解 |
